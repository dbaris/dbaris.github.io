OPEN SOURCE EMBASSY

Set against a tense geopolitical history and a nuanced present-day digital landscape, the Open Source Embassy proposes an extension to the existing US Embassy compound in Moscow, Russia focused on cybersecurity diplomacy and education.

Serving as the work space for a new international cybersecurity task force, the multipurpose embassy grounds itself in interdisciplinary principles drawn from the Open Source software movement - transparency, accessibility, and collaboration - in the hopes of improving international digital diplomacy.

The embassy design employs a security gradient to balance safety requirements for limited access with the desire to expand transparency and accessiblity through education. Glass, double height overlooks, and observation rooms are used to enable visual access when physical access is not possible.

The basement levels stores a data center, providing the building with computing resources as well as a physical heat source while connecting the embassy as a node in Moscow’s robust digital network of tech companies, universities, internet exchange points, and data centers. The building’s security gradient limits public access to critical work and infrastructural spaces, but uses glass, double-height ceilings, and overlook rooms to provide visual access to all spaces.

Cooling towers cut through the building’s core to distribute heat and emerge as a landmark gesture evocative of Russian Constructivist monumental infrastructure projects such as Tatlin’s Tower. On the interior, the cooling core towers guide a spiral ramped circulation interface that enables public viewing and access into cybersecurity policy, education, and infrastructural initiatives.
